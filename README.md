# AI Resume Skill Matcher

AI Resume Skill Matcher is a modern, interactive web application built with React that helps job seekers analyze how well their resume matches a job description. It extracts key skills, calculates a match score, highlights missing skills, and recommends relevant job roles based on the user’s resume.
The application features a clean UI, dark/light mode, resume upload support, and real-time skill comparison to help users improve their job readiness and target the right roles.

## Features

-  Upload resume files (.txt, .docx) or paste resume text
-  Automatic skill extraction from resume and job description
-  Match score calculation using skill similarity
-  Matched skills and ❌ missing skills breakdown
-  AI-style job recommendations based on resume skills
-  Dark mode / Light mode toggle
-  Fast, client-side processing (no backend required)
-  Modern UI built with Tailwind CSS and Lucide icons
